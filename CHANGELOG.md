# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.3.0](changelog/0.3.x/0.3.0.md) — 2026-10-25

Daily refresh uses FCC listing timestamps and publication-day coverage, preserves literal registry text, and serves a guide for multi-step ULS investigations.

## [0.2.1](changelog/0.2.x/0.2.1.md) — 2026-10-25

License lookups list microwave paths with receive-site coordinates and receiver callsigns, the daily refresh skips files for service groups the index does not hold, and the mirror CLI ships compiled so npm and .mcpb installs can build their index.

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-13

Restore unnumbered FCC antenna filings, expose filed site roles, and decode station classes with bounded output budgets.

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-02 · 🛡️ Security

Scheduled ingest runs in a child process, the search tools gain market-code filters, and individual licensees' site names are withheld under redaction.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — five read-only tools and a license resource over a local index of FCC Universal Licensing System bulk files: search licenses and leases, read a license in full, find transmitter sites near a point, and see who is authorized on a frequency or band.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
