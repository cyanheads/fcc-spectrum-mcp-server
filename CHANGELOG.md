# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-02 · 🛡️ Security

Scheduled ingest runs in a child process, the search tools gain market-code filters, and individual licensees' site names are withheld under redaction.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — five read-only tools and a license resource over a local index of FCC Universal Licensing System bulk files: search licenses and leases, read a license in full, find transmitter sites near a point, and see who is authorized on a frequency or band.
