# 0.2.0 — 2026-10-13

## Changed

- **Filed site roles** appear as `locationClassCode` and known FCC `locationClassLabel` on license detail, nearby sites, and single-site frequency assignments; nearby `location_class` filters by C/L/P/R/T before totals and paging. Shared-number assignments omit site-specific classes. [#24](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/24)
- **Station classes** are decoded by `fcc_spectrum_list_reference` with `topic: "station_classes"`, using the FCC's 266-code table. Technical outputs preserve filed codes and point to this lookup; unknown codes remain valid without invented labels. [#28](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/28)
- **Output budgets** accept excessive positive integers and clamp to existing ceilings with requested/effective notices, preserving continuation and empty-result guidance. Clamping alone does not mark complete results truncated. [#26](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/26)
- **Registry launch metadata** uses `npx`, omits npm-script arguments, and fixes the HTTP entry's `MCP_TRANSPORT_TYPE` to `http`.
- **Framework maintenance** synchronizes skills, packaging and local checks, CodeQL language categories, distribution exclusions, and the `LOG_LLM_INTERACTIONS` configuration example; Docker prunes musl-only packages from its glibc runtime.

## Fixed

- **Reference filters** reject nonblank tokenless filters on searchable topics with `invalid_filter`; unsupported topics disclose ignored filters alongside coverage/readiness guidance. [#22](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/22)
- **All-zero coordinate placeholders** omit invalid decimals while retaining filed DMS and state; existing stored placeholders are repaired in place, and a zero on only one axis remains valid. [#23](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/23)
- **Unnumbered antenna filings** remain independent records without fabricated numbers or frequency associations, including exact duplicates and whole-location paging. Existing generations remain readable with an antenna-completeness notice; run `bun run mirror:init` to restore previously discarded rows even when weekly snapshots are unchanged. [#30](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/30)
