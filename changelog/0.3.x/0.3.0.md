# 0.3.0 — 2026-10-25

## Added

- Add the `fcc-spectrum-guide` skill resource at `skill://fcc-spectrum-guide/SKILL.md` for multi-step ULS investigations.

## Changed

- **Daily refresh** resolves Eastern publication timestamps from the FCC listing, using HEAD only when a retained timestamp is unresolved. [#33](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/33)
- **Packaging** ships the guide in npm, Docker, and desktop bundles, adds Agent Plugins manifests, and strips dependency build files from desktop bundles.
- **Documentation** clarifies investigation limits, service coverage, pagination, and refresh recovery; framework tooling and authoring guidance are synchronized.

## Fixed

- **Daily coverage** checks post-checkpoint publication dates across the rotating window; scheduled recovery retries refresh after a completed rebuild and rejects a skipped rebuild that leaves the gap. [#34](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/34)
- **Registry text and ingest errors** render literally in CommonMark, including quoted error lines and nested antenna fields. [#35](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/35)

## Dependencies

- `@cyanheads/mcp-ts-core` ^0.13.16 → ^0.13.18
- Add `markdown-it` ^15.0.3 and `@types/markdown-it` ^14.2.0 as development dependencies for rendering tests.
- **Install policy** lowers the minimum release age from three days to one day.
