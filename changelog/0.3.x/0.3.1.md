# 0.3.1 — 2026-11-17

## Added

- **`fcc_spectrum_find_transmitters` `radius_km`** accepts up to 230 km, on by default; `FCC_SPECTRUM_WIDE_RADIUS=false` restores the 100 km ceiling. Calls over 100 km log one line and increment the `fcc_spectrum.find_transmitters.wide_radius` counter. [#39](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/39)
- **`fcc_spectrum_get_license`** names each lease's lessee (`lesseeName`, `lesseeRedacted`) and each parent's licensee (`licenseeName`, `licenseeRedacted`), under the individual-licensee redaction rule. [#40](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/40)
- **`fcc_spectrum_search_licenses`** takes inclusive `expires_after`, `expires_before`, `granted_after`, and `granted_before` date bounds, echoed in `appliedFilters`; an `_after` later than its `_before` fails the new `invalid_date_range` error. [#42](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/42)

## Changed

- **Coordinate descriptions** on `fcc_spectrum_find_transmitters` advertise decimal degrees only, matching the `number` schema; string and DMS input still parses. [#43](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/43)
- **`fcc-spectrum-guide` skill** 1.0 → 1.1 reads lessee and lessor names from the `get_license` lists.
- **Framework** `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22 with the synced framework skills and scripts; `engines.bun` is now ≥1.4.4, the minimum the framework's SQLite store opens on.
- **Scheduled ingest** skips while another process holds the mirror sync lease, and a signal stop exits 0 with a notice.
- **`mirror_sync_state`** gains a `mode` column the first time framework 0.13.22 opens an index built by an earlier release.

## Fixed

- **Cursors** carry a digest of the search inputs; one reused with a changed filter, center, radius, band, or date bound fails `invalid_cursor` instead of skipping or repeating rows. Cursors minted by 0.3.0 still continue. [#38](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/38)
- **`mirror:init` and `mirror:refresh`** report `pagesFetched`, `total`, and per-group (rebuild) or per-file (refresh) `licenses` counts in place of `recordsApplied` and `tombstonesApplied`, which always read 0. [#44](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/44)
- **kHz and GHz frequencies** convert to MHz rounded to the millihertz, so they match their MHz spelling: a cursor carries across the two, and `appliedFilters` no longer echoes values like 851.0124999999999.
- **`fcc_spectrum_search_licenses`** zero-hit notice for a callsign no longer claims the callsign is absent when a status or date filter excluded it.
