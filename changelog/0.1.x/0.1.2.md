# 0.1.2 — 2026-10-02

## Added

- **`market_code` filter** on `fcc_spectrum_search_licenses` and `fcc_spectrum_search_frequencies`, matched exactly (`PEA016`, `CMA020`, `D06037`, `NW`); case, spaces, and hyphens are ignored and the digits zero-padded (`pea16` → `PEA016`) ([#16](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/16)).
- **`frn` filter** on `fcc_spectrum_search_frequencies`, normalized as on `fcc_spectrum_search_licenses`. Both `frn` and `market_code` test the license there, so they filter site and market rows alike ([#16](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/16)).
- **`location_number`** on `fcc_spectrum_get_license` starts the location window at a `locationNumber` from the search tools, or at the next filed one when the record files no such location; with a nonzero `location_offset` it fails with `location_start_conflict` ([#17](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/17)).
- **`location_type` filter** on `fcc_spectrum_find_transmitters`: one ULS location type code, case-insensitive (`F` keeps fixed sites only) ([#14](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/14)).
- **Hosted endpoint** at `https://fcc-spectrum.caseyjhand.com/mcp` (Streamable HTTP), listed as a `server.json` remote and in the README.

## Changed

- **Scheduled HTTP ingest runs in a child process**: the weekly rebuild and daily refresh each run the compiled `ingest-job.js` on the server's runtime, so tool calls and `/healthz` keep answering through the index's synchronous write steps. The job's log lines reach the server log, and a non-zero exit or a kill logs `Scheduled ULS <label> failed` ([#10](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/10)).
- **Shutdown stops a running job**: SIGTERM, on which it saves its progress and releases the ingest lock, then SIGKILL after 5 s; its rebuild resumes at the next run. A lock left by a job killed with its container is cleared at the next startup ([#10](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/10)).
- **Schema 5** adds a partial `licenses(market_code)` index. An existing index upgrades to schema 5 in place on its first open, which takes about 3 s on a full index (longer on a cold or busy host) and needs no rebuild.

## Fixed

- **Market-block `state` matching** on `fcc_spectrum_search_frequencies` uses the FCC market-area definitions, county FIPS codes, and the license's own sites, not only a state code in the 30-character market name, which missed MTAs, REAs, and most rural CMAs ([#13](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/13)). The market-to-state table ships as `market-states.json`; nationwide and Gulf of Mexico markets match no state.
- **Mobile and temporary-fixed operating areas** on `fcc_spectrum_find_transmitters` carry `locationTypeLabel` and `radiusKm`, and are described as returned at their filed center, which `distanceKm` measures to; `fcc_spectrum_search_frequencies` single-site rows add `locationTypeCode`, `locationTypeLabel`, and `radiusKm` ([#14](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/14)).
- **`asrNumber` appears only for a registration number**, seven digits other than the `9999999` placeholder; `N/A`, application file numbers, and other filed values are omitted, with no rebuild needed ([#15](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/15)).
- **`fcc_spectrum_get_license` lists every location number in its window**, with `antennas: []` when `max_frequencies` cuts its rows; a number filed only on frequency rows past the cut was counted but never listed, so paging skipped it ([#18](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/18)).
- **A failed index pointer read is retried on the next call** instead of after the one-minute check interval.

## Security

- **Individual licensees' site names are withheld under redaction** ([#12](https://github.com/cyanheads/fcc-spectrum-mcp-server/issues/12)). While redaction was on, `fcc_spectrum_get_license` and `fcc-spectrum://license/{callsign}` returned an individual's site names, and some individuals file their own name as a site name; site names on an individual's record are now omitted with its street addresses.
