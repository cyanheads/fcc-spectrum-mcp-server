# 0.1.1 — 2026-10-01

## Added

- **`fcc_spectrum_search_licenses`** — search licenses and spectrum leases by callsign, licensee name, FRN, radio service, or licensee mailing state; active records by default (`status: "any"` for all), cursor-paged, each row carrying the `usi` that `fcc_spectrum_get_license` takes.
- **`fcc_spectrum_get_license`** — one license or lease in full by callsign or USI: licensee, status and dates, locations, antennas, frequency rows with power and emission designators, market blocks, and lease links both ways. Large records page by location, `max_frequencies` (1–1000), and lease.
- **`fcc_spectrum_find_transmitters`** — licensed transmitter sites within 0.1–100 km of a decimal or DMS coordinate, nearest first, each with distance, elevation, structure height, and its authorized frequencies; filter by frequency or band (kHz, MHz, GHz), radio service, and live status.
- **`fcc_spectrum_search_frequencies`** — authorizations whose occupied band overlaps a frequency or band, as site assignments and market-area spectrum blocks, filtered by state, radio service, licensee, and live status. On dense bands `totalCount` can be a lower bound (`totalIsLowerBound`).
- **`fcc_spectrum_list_reference`** — decodes radio service codes, license statuses, location and antenna types, applicant types, and amateur operator classes; topic `coverage` reports index build state, per-group counts and snapshot times, and the redaction setting, and works before the index is built.
- **`fcc-spectrum://license/{callsign}`** — the first page `fcc_spectrum_get_license` returns for a callsign, as JSON, with a `notice` naming the call that reads the rest.
- **Local ULS index** — every request reads an embedded SQLite index of the FCC's weekly and daily ULS bulk files: keyless, with no FCC call at request time. Default coverage is land mobile, microwave, cellular, market-area, paging, coast, BRS/EBS, amateur, and spectrum leases; broadcast stations and satellite earth stations are not included.
- **Index lifecycle** — `mirror:init` builds the index (required once; until then data tools fail with `index_not_ready`), `mirror:refresh` applies daily files, and `mirror:verify` checks it. Under HTTP the server runs the weekly rebuild and daily refresh itself; under stdio, schedule the scripts.
- **Configuration** — `FCC_SPECTRUM_MIRROR_DIR` (index directory), `FCC_SPECTRUM_SERVICES` (weekly service groups; `gmrs`, `ship`, `aircr` opt-in), `FCC_SPECTRUM_REDACT_INDIVIDUALS`, and `FCC_SPECTRUM_BASE_URL` (bulk host, read only when building or refreshing).
- **Individual-licensee redaction** — on by default; only `false`, `0`, `no`, or `off` disables it. Individuals' names and cities are withheld (`licenseeRedacted: true`) and excluded from name search, trustee names are withheld, and contact details are never ingested for anyone.
- **Data terms** — license data is the FCC Universal Licensing System (ULS), a US government work in the public domain; the package ships none of it, and operators download it when building the index. Credit "FCC Universal Licensing System (ULS)" with each response's `dataAsOf`.
